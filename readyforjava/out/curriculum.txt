@TOPIC basics @@ Program Basics
@EXPLAIN
Every Java program lives inside a class, and execution starts at the main method.
Statements end with a semicolon; blocks are wrapped in curly braces.

    public class Hello {
        public static void main(String[] args) {
            System.out.println("Hello, world!"); // prints and moves to a new line
            System.out.print("no newline");
        }
    }

println adds a newline after the text; print does not.

@TOPIC variables @@ Variables and Data Types
@EXPLAIN

@TOPIC conditionals @@ Conditionals
@EXPLAIN
Use if / else if / else to choose between paths, and switch to select on a single value.

    if (score >= 90) {
        System.out.println("A");
    } else if (score >= 80) {
        System.out.println("B");
    } else {

    }

        case 1: System.out.println("Mon"); break;
        default: System.out.println("Other");
    }

Compare Strings with equals(), never ==. Without break, a switch falls through to the next case.

@TOPIC loops @@ Loops
@EXPLAIN

    do { n++; } while (n < 3);
    for (int v : numbers) { System.out.println(v); }

@TOPIC inheritance @@ Inheritance and Interfaces
@EXPLAIN
A subclass inherits fields and methods with extends and can override them. An interface
declares behavior that classes promise to provide with implements.

    class Animal { void speak() { System.out.println("..."); } }
    class Cat extends Animal {
        @Override void speak() { System.out.println("Meow"); }
    }
    interface Flyer { void fly(); }
    class Bird implements Flyer { public void fly() { } }

A class extends one class but may implement many interfaces. Polymorphism lets an Animal
variable hold a Cat.

@TOPIC exceptions @@ Exceptions
@EXPLAIN
Exceptions signal runtime problems. Handle them with try / catch / finally, or raise one with throw.

    try {
        int x = Integer.parseInt("abc");
    } catch (NumberFormatException e) {
        System.out.println("Not a number");
    } finally {
        System.out.println("always runs");
    }

Checked exceptions (like IOException) must be caught or declared with throws.
